# Источники вдохновения и заимствования для интерфейса Yandex Messenger

Так как наше приложение написано на **Rust + GTK4**, заимствовать интерфейс напрямую из официального клиента Telegram (написанного на C++ и Qt) или веб-клиентов на React/Electron будет сложно из-за несовместимости UI-фреймворков. 

Ниже представлены лучшие open-source проекты на GitHub/GitLab с передовым дизайном, использующие тот же стек (Rust + GTK4 + libadwaita) или близкие технологии, из которых мы можем перенять архитектуру интерфейса, CSS-стили и логику разметки.

---

## 1. Paper Plane (Telegram-клиент)
* **Репозиторий:** [github.com/paper-plane-developers/paper-plane](https://github.com/paper-plane-developers/paper-plane)
* **Стек:** Rust, GTK4, libadwaita
* **Что можно заимствовать:**
  * **Layout чата и списка диалогов:** Это неофициальный клиент Telegram, поэтому структура интерфейса здесь максимально приближена к оригиналу.
  * **Стили сообщений (Bubble):** Отличная реализация "облачков" сообщений с поддержкой скруглений углов в зависимости от того, идет ли сообщение подряд от одного автора.
  * **Панель ввода:** Готовая логика для текстового поля с автовысотой, кнопками смайликов и вложений.
  * **CSS-темы:** Готовые стили для темной и светлой тем, адаптированные под мессенджер.

## 2. Fractal (Matrix-клиент для GNOME)
* **Репозиторий:** [gitlab.gnome.org/GNOME/fractal](https://gitlab.gnome.org/GNOME/fractal)
* **Стек:** Rust, GTK4, libadwaita
* **Что можно заимствовать:**
  * **Виртуализированные списки сообщений:** Fractal использует `GtkListView` для плавной прокрутки тысяч сообщений без лагов. Мы можем перенять их подход к фабрикам элементов (Item Factories) для рендеринга сообщений.
  * **Рендеринг медиа-файлов:** Логика отображения картинок, видео, голосовых сообщений (с волновым графиком) и превью ссылок.
  * **Индикатор печати:** Плавные анимации точек при наборе текста собеседником.
  * **Поиск по сообщениям:** Интегрированный UI поиска внутри чата с подсветкой совпадений.

## 3. Tuba (Mastodon-клиент)
* **Репозиторий:** [github.com/Geopard/Tuba](https://github.com/Geopard/Tuba)
* **Стек:** C, GTK4, libadwaita (но логика UI легко переносится на Rust)
* **Что можно заимствовать:**
  * **Эстетика и анимации:** Tuba признан одним из самых красивых приложений в экосистеме GNOME. Оттуда стоит перенять стили скруглений, hover-эффекты и переходы.
  * **Профили пользователей и настройки:** Красивое оформление боковых панелей с информацией о пользователе/чате и диалоговых окон настроек.

## 4. Cinny (Matrix веб-клиент)
* **Репозиторий:** [github.com/cinnyapp/cinny](https://github.com/cinnyapp/cinny)
* **Стек:** React, Tailwind CSS (веб)
* **Что можно заимствовать:**
  * **Визуальные концепции:** Cinny обладает потрясающим современным интерфейсом в стиле Discord/Telegram. Несмотря на другой стек, мы можем заимствовать их цветовую палитру, размеры отступов (padding/margin) и логику группировки элементов UI для переноса в наш `theme.css`.

---

## План действий по улучшению нашего интерфейса:

1. **Интеграция Libadwaita:**
   Если мы еще не используем `libadwaita`, ее стоит подключить. Она дает готовые современные виджеты (адаптивные панели, красивые переключатели, готовые стили для списков), которые избавят нас от ощущения "интерфейса на коленке".
   
2. **Перенос CSS-стилей:**
   За основу нашего `src/ui/theme.css` можно взять CSS-файлы из репозитория **Paper Plane**, адаптировав их под наши классы виджетов. Это сразу даст красивые hover-эффекты, правильные тени и скругления "облачков" сообщений.

3. **Оптимизация разметки чата:**
   Переписать контейнеры сообщений с использованием наработок из **Fractal**, чтобы сообщения выглядели аккуратно сгруппированными, с правильными отступами и аватарами.
