# История изменений (Changelog)

[English version](CHANGELOG.md)

Все значимые изменения в проекте документируются в этом файле.
Формат основан на руководстве [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/) и соответствует [семантическому версионированию](https://semver.org/lang/ru/).

Текущий релиз: **2.173.0** (2026-08-15).

---

## 2.173.0 - 2026-08-15

### Добавлено
* **Тема Telegram Desktop night**: токены из `night.tdesktop-theme` (`dialogsBg`, `msgIn` / `msgOut`, синяя кнопка отправки).
* **Разделение в стиле nheko**: список диалогов ~32% ширины (макс. 420px), плотные строки, аватары 54px.
* **Сплошное выделение** (`dialogsBgActive`) вместо glow-хрома.
* **Адаптивный сайдбар**: сжимается и ограничивается, не вылезает за край.
* **Автоскролл** к последнему сообщению при открытии чата.

### Изменено
* Визуальный язык по умолчанию — night-тема Telegram/nheko, а не прежний Obsidian-like glow.

### Известные ограничения
* Голосовые сообщения и Telemost WebRTC по-прежнему заглушки (скрыты без feature flags).
* Видеоплеер не реализован.
* Имена RPC действий чата — best-effort reverse-engineering; локальный UI всё равно обновляется.

## 2.168.0 - 2026-08-08

## 2.167.0 - 2026-08-08

### Добавлено
* **Session внутри login** (без Python): WebView login сохраняет Passport cookies (`session.json`) + CSRF; при необходимости догружает `yandex.ru/chat`.
* **Outbox**: неотправленные сообщения пишутся на диск (`outbox.json`), retry при WS Connected и каждые 45с; UI показывает pending bubble (`sent=false`).

### Изменено
* `HttpClient.session_cookies` — Mutex + `reload_session()` / `apply_session()`.
* Подсказка при старте, если session отсутствует.

## 2.166.0 - 2026-08-08

### Добавлено
* **Reply / Edit**: ответ и редактирование реально уходят на сервер (`send_text_message_ex`).
* **Desktop notifications** через `notify-rust` (mute чата + глобальный флаг настроек).
* **System tray** (StatusNotifierItem / `ksni`): показать, выход, badge непрочитанных, close→tray.
* **Действия чата**: mark read / mute / pin / archive / delete (session RPC, best-effort) + локальный UI.
* **Mark as read** при открытии чата.
* **Окно настроек**: уведомления, трей, тёмная тема.
* **RU-превью** сообщений (`📷 Фото`, `Нет сообщений`, …).

### Исправлено
* Hardcoded yuid fallback убран — без session yuid отправка падает явно.
* Сборка Telemost UI (GTK4 children API).

### Известные ограничения
* Session.json по-прежнему нужен для полной history/WS/files.
* Voice/video/Telemost WebRTC — заглушки.
* Chat action RPC-имена могут не совпасть с сервером — UI всё равно обновляется локально.

## 2.165.0 - 2026-08-08

### Добавлено
* **Флаги фич для голосовых и Телемоста**:
  - Добавлена переменная окружения `YM_ENABLE_VOICE` для управления видимостью элементов интерфейса голосовых сообщений (волна, кнопки воспроизведения/записи).
  - Добавлена переменная окружения `YM_ENABLE_TELEMOST_UI` для управления видимостью элементов интерфейса Телемоста (видеозвонки) в заголовке чата.
  - Когда флаг выключен, соответствующие элементы-заглушки скрываются из интерфейса.
* **Заглушки помечены комментариями**:
  - Все реализации-заглушки теперь аннотированы комментариями `// STUB:` для удобной идентификации при разработке.
* **Дымовые тесты для предпросмотра сообщений и настроек**:
  - Добавлены дымовые тесты, покрывающие рендеринг предпросмотра сообщений и сохранение настроек.
* **Очистка кода**:
  - Удалены неиспользуемые импорты по всему проекту.
  - Добавлены атрибуты `#[allow]` для устранения предупреждений линтера.

### Изменено
* 0 предупреждений при сборке, 13 тестов проходят.

### Известные ограничения
* **Голосовые сообщения**: заглушка (скрыты по умолчанию, включить через `YM_ENABLE_VOICE`)
* **Видеозвонки (Телемост)**: заглушка (скрыты по умолчанию, включить через `YM_ENABLE_TELEMOST_UI`)
* **Уведомления**: заглушка (только stdout/stderr, нет системных уведомлений)
* **Системный трей**: заглушка (не реализовано)
* **Контекстные меню списка чатов**: заглушка (не реализовано)
* **Загрузка/выгрузка файлов**: не реализовано
* **История звонков**: не реализовано
* **Реакции на сообщения**: не реализовано

## 2.162.0 - 2026-06-29

### Добавлено
* **Интеграция Libadwaita**:
  - Приложение переведено на использование `libadwaita` (`adw::Application` / `adw::ApplicationWindow`).
  - Стандартные плейсхолдеры аватаров заменены на современный виджет `adw::Avatar` с автоматической поддержкой инициалов и палитры цветов.
  - Добавлен компонент `adw::HeaderBar` в верхнюю часть интерфейса.
* **Улучшения списка чатов**:
  - Внедрено кэширование текстур аватаров в оперативной памяти (`AVATAR_CACHE`), что устранило мерцание и повторные загрузки при прокрутке.
  - Реализован индикатор закрепленных чатов (булавка 📌) в строках списка.
  - Добавлена автоматическая сортировка чатов: закрепленные чаты всегда располагаются вверху списка, остальные сортируются по времени последнего сообщения.
* **Редактор и ввод сообщений**:
  - Обычное поле ввода заменено на многострочный `TextView` с адаптивной высотой (до 120px) в `ScrolledWindow`.
  - Отправка сообщения теперь осуществляется по клавише `Enter`, а перенос строки — по `Shift+Enter`.
  - Добавлена функция быстрого редактирования последнего отправленного сообщения по клавише `Up` при пустом вводе.
* **Улучшения чата и истории**:
  - Добавлено локальное кэширование строк сообщений (`message_rows`) для оптимизации UI и предотвращения лишних перерисовок.
  - Добавлена асинхронная загрузка и сохранение L2-кэша (`load_cache_l2_async` / `save_cache_l2_async`) в JSON-файлы через фоновый поток.
  - При выборе чата история мгновенно отображается из кэша, пока идет фоновый сетевой запрос.
  - Добавлен автоматический скролл вниз списка сообщений при переключении чатов или получении новых сообщений.
  - Реализованы визуальные разделители дат («Сегодня», «Вчера», даты).
  - Внедрена обработка сообщений-стикеров с отображением картинок размером 128x128px.
  - Внедрен режим «только эмодзи» (увеличенный размер эмодзи до 40px без пузыря баббла при отправке от 1 до 3 эмодзи).
  - Добавлены меню вложений (отправка файла, создание опроса, планирование) и меню заголовка (информация о чате, включение/выключение уведомлений).

### Изменено
* Контейнер сайдбара и чата переведен на `gtk::Paned` с регулируемой границей и поддержкой компактного режима сайдбара (скрытие текста при ширине < 180px).
* Базовая ширина сайдбара уменьшена с 320 до 260px.
* В случае сбоя или пустого каталога стикеров на сервере приложение переключается на встроенные mock-стикеры.

### Исправлено
* Устранена критическая ошибка типов `E0308 mismatched types` in `src/ui/chat_list.rs` при обработке коллбеков.
* Исправлены GTK layout баги (бесконечный цикл и растягивание виджетов до `1048576px`) за счет правильной настройки `hexpand`/`vexpand`.
* Исправлена отправка сообщений и привязка коллбеков в `ChatView` через `bind_callbacks`.

## 2.160.0 - 2026-05-10

### Изменено
* **Неблокирующий OAuth-диалог**:
  - Локальный callback-сервер переведен на фоновый поток, что предотвращает блокировку основного GTK-цикла.

* **Обновление стилей**:
  - Добавлены градиенты к кнопкам, радиальное свечение на фоне окна входа и мягкие тени при фокусе на полях ввода.

### Исправлено
